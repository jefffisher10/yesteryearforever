# MOUND
### Monitoring Outdoor Urban Naturalist Device
*A solar-powered backyard sensor observatory — Central Ohio*

Part of the Fisher project family alongside the Adena rover and Hopewell rockets.

---

## What is MOUND?

MOUND is a small autonomous outdoor sensor station built on a Raspberry Pi Zero W, powered by a solar panel and battery pack. It quietly monitors the backyard environment and logs data automatically every 30 minutes — a personal naturalist's field instrument inspired by unmanned space probes. Simple by design. The journey is the point.

Data is published automatically to [yesteryearforever.xyz/mound](https://yesteryearforever.xyz/mound/data_archive.html)

## Hardware

| Component | Purpose | Interface |
|-----------|---------|-----------|
| Raspberry Pi Zero W (2017) | Outdoor node | — |
| BME280 | Temperature, humidity, barometric pressure | I2C 0x76 |
| TSL2591 | Light / lux sensor | I2C 0x29 |
| DS18B20 | Waterproof soil temperature probe | 1-Wire GPIO4 |
| Capacitive soil moisture sensor | Soil moisture | Analog via ADS1115 A0 |
| FC-37 rain sensor | Rain detection | Analog ADS1115 A1 + GPIO17 |
| ADS1115 | 16-bit 4-channel ADC | I2C 0x48 |
| INA219 | Battery voltage/current monitor (battery-side) | I2C 0x40 |
| Raspberry Pi Camera Rev 1.3 | Photography | CSI ribbon |
| Newpowa NPC-PHL10A PWM charge controller | Power management, battery type SEL, load mode Always On | USB 5V out → Pi |
| 2x 12V SLA/AGM lead-acid batteries (wired in parallel) | Battery storage | — |
| Newpowa 10W 12V solar panel | Solar charging (facing east) | via blocking diode |
| Newpowa 20W 12V solar panel | Solar charging (facing west) | via blocking diode |
| 2x 1N5822 Schottky diodes | Prevent panel backfeed when combined in parallel | — |

**Retired hardware:** Waveshare Solar Power Manager (D), Waveshare 6V 5W panel, 3x/4x 18650 Li-ion cells — replaced due to chronic overnight power failure caused by insufficient charging margin under tree shade. See `POWER_HISTORY.md` (or project notes) for the full diagnostic writeup.

## Power System

Two solar panels of different wattage, facing different directions to spread coverage across tree-shaded gaps in the sky, are combined in parallel through individual blocking diodes before reaching the charge controller. This prevents a sunlit panel from backfeeding current into a shaded one.

```
Panel 1 (10W, facing East) --[+]--> [Diode 1] --+
                                                  +--> Controller PV+
Panel 2 (20W, facing West) --[+]--> [Diode 2] --+

Panel 1 (-) ------------------------------------+
                                                  +--> Controller PV-
Panel 2 (-) ------------------------------------+
```

The controller charges two 12V SLA/AGM batteries wired in parallel (battery type set to **SEL** on the controller), using 4-stage PWM charging (Boost/Float). The Pi is powered from the controller's built-in 5V/2A USB output, with the load mode set to **Always On (mode 17)** so the Pi powers back up automatically after any power interruption, with no manual switch required.

The INA219 power monitor sits in series on the battery's positive lead, between the battery and the controller's BAT+ terminal — this gives true battery voltage and real charge/discharge current direction, rather than a flat regulated 5V reading.

```
Battery (+) --> INA219 VIN+
INA219 VIN- --> Controller BAT+
Battery (-) --> Controller BAT- (direct)
```

See `mound_wiring.html` for the full sensor-level wiring reference.

## Data Format

Monthly log files (`data/YYYY-MM.txt`):

```
# timestamp, temp_f, humidity_pct, pressure_hpa, lux, soil_temp_f, soil_moisture_raw, rain, voltage, current_ma
2026-09-02 12:20:03, 101.2, 47.0, 991.3, 1989.0, 86.7, 12480, 0, 13.87, 67.4
```

| Field | Notes |
|-------|-------|
| lux = 99999 | Sensor overflow — too much direct sunlight |
| rain = 0 | Dry |
| rain = 1 | Rain detected |
| soil moisture | Lower = wetter, higher = dryer |
| voltage | True battery voltage (battery-side INA219 placement) |
| current_ma | Negative = charging, Positive = discharging |

## Crontab

```
*/10 * * * * python /home/ramblinray/mound/scripts/log_sensors.py
*/10 * * * * python /home/ramblinray/mound/scripts/update_site.py
*/30 * * * * python /home/ramblinray/mound/scripts/camera.py
```

`camera.py` captures a live shot every 30 minutes, overwrites `images/latest.jpg` on the site, and separately keeps one permanent shot per day (`images/noon/YYYY-MM-DD.jpg`), reusing the same capture rather than shooting twice.

## Useful Commands

```bash
# Check latest readings
tail -5 ~/mound/data/2026-09.txt

# Check error log
cat ~/mound/data/errors.txt

# Run sensor script manually
python ~/mound/scripts/log_sensors.py

# Run full site update manually
python ~/mound/scripts/update_site.py

# Take a photo
rpicam-still --vflip --hflip -o ~/mound/test.jpg

# Check WiFi signal
iwconfig wlan0

# Check I2C devices
sudo i2cdetect -y 1

# Check crontab
crontab -l

# Check cron logs
journalctl -u cron --since "1 hour ago" | tail -30

# Check battery voltage/current trend (hourly, last week)
awk -F', ' '$1 ~ /:00:/ {print $1", V="$9", mA="$10}' ~/mound/data/2026-09.txt | tail -168
```
